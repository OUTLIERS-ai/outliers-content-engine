# My opinions: the quick-start list

> **How to fill this in.** Write 10 opinions you actually believe and have said out loud, to a client,
> a friend or on a call. Write each one the way you said it, not the way you would polish it for a
> post. The writer copies your words into the post exactly, so rough is better than tidy.
> An opinion belongs here if somebody would disagree with it. "Good service matters" is not an
> opinion. "Most of my competitors undercharge because they are scared" is.
> Fill every field marked [FILL IN: ...]. Tier 1 lands hardest, tier 2 is an argument, tier 3 is a
> working view.
> Your first wave uses each of these 10 once, so it is 10 drafts. For waves of 20, add entries 11,
> 12 and on in the same layout until you have at least 20. Never use the same opinion twice in 1
> wave.
> Later you can replace this file with opinions mined from your transcripts
> (`prompts/mine-a-month.md`). Keep this file until then.
> You can delete these instruction lines once the file is filled in. No program reads them.
> See `example/your-voice/opinions/OPINIONS.md` for a filled version.

A brief names an opinion like this: `your-voice/opinions/OPINIONS.md entry 3`.
